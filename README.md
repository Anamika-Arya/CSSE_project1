# SocietyHub – College Society Management System

Production-ready frontend for a College Society Management System built with **React 19**, **Vite 7**, **TypeScript**, **Tailwind CSS v3.4**, **Framer Motion**, **Recharts**, and **React Router v7**.

## Features

- **Theme system**: Light/Dark mode with `dark` class on `<html>`, animated sun/moon toggle, gradient backgrounds, localStorage persistence, glassmorphism cards
- **Design system**: 8px grid, `rounded-3xl`, soft shadows, Inter font, neon accents (cyan `#00f5ff`, purple `#a855f7`)
- **Layout**: Collapsible glass sidebar (desktop), bottom nav (mobile), navbar with search, notifications, profile dropdown, theme toggle
- **Pages**: Dashboard (stats, line/doughnut charts, activity, events), Societies (3D tilt cards), Events (capacity bars, status badges), AI (recommendations + floating chatbot)
- **Animations**: Page fade/slide, card hover scale + lift, sidebar collapse, button glow, floating chatbot bounce + ring pulse
- **Stack**: Context API only (no Redux), lazy-loaded routes, Tailwind + clsx (no inline styles)

## Setup

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Project structure

- `src/components/` – ThemeToggle, GlassCard, StatCard, SocietyCard, EventCard, Sidebar, Navbar, Layout
- `src/context/` – ThemeContext
- `src/pages/` – Dashboard, Societies, Events, AI
- `src/hooks/` – Reserved for custom hooks

## Tech stack

- React 19, Vite 7, TypeScript
- Tailwind CSS 3.4 (custom colors, shadows, dark mode)
- Framer Motion (page transitions, hover, 3D tilt)
- lucide-react (icons)
- Recharts (line + doughnut)
- React Router 7.4+ (lazy routes)
- clsx (class names)
